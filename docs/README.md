## 工程入口

| 文档 | 用途 |
|---|---|
| [LOCAL_SETUP.md](LOCAL_SETUP.md) | 本机运行、密钥代理、浏览器验收 |
| [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md) | 已实现、部分实现、未接主链和未实现状态 |
| [INTERVIEW_GUIDE.md](INTERVIEW_GUIDE.md) | 面试讲解提纲、演示流程和已知限制 |
| [扇出改造-设计共识与接续手册.md](扇出改造-设计共识与接续手册.md) | 历史共识、目标架构和接续规则 |

## 阅读顺序

1. 从根目录 `README.md` 获取项目定位。
2. 从 `LOCAL_SETUP.md` 验证可运行性。
3. 从 `IMPLEMENTATION_STATUS.md` 核对实现范围。
4. 从 `INTERVIEW_GUIDE.md` 准备演示与回答。
5. 从设计共识手册和工程规格了解目标架构与未解决问题。

> 历史设计文档和目标架构不应直接等同于当前实现状态。以源码和 `IMPLEMENTATION_STATUS.md` 为准。
